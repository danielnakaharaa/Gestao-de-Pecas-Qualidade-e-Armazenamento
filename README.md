# Gestao-de-Pecas-Qualidade-e-Armazenamento

# Sistema de Controle de Peças

Projeto desenvolvido em Python para controle e classificação de peças.

## Objetivo

O sistema recebe as informações de uma peça e verifica se ela atende aos requisitos definidos.

A peça é classificada como:

- Aprovada
- Reprovada

As peças aprovadas são armazenadas em caixas e as peças reprovadas são armazenadas em um arquivo separado.

## Regras de aprovação

A peça é aprovada quando:

- O peso está entre 95 e 105
- A cor é azul ou verde
- O comprimento está entre 10 e 20

## Funcionalidades

1. Cadastrar nova peça
2. Listar peças aprovadas e reprovadas
3. Remover peça cadastrada
4. Listar caixas fechadas
5. Gerar relatório final
6. Sair

## Tecnologias

- Python
- JSON
